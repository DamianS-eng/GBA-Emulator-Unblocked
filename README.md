# Welcome to the GBA emulator

GBA Emulator is a free, online GBA emulator with 150+ Games to play!

## What is this?

This is a fork of a fork down the line starting from a Javascript GameBoy Advance emulator by [taisel](https://github.com/taisel/IodineGBA).

The layout is very similar to the layout of the original repository, which is a home page with a directory listing that then picks a binary and loads it into the emulator.

## What are some to-dos?

There are several problems with the current fork I pulled from, but most of those problems are from obsolesence. The HTML, the CSS, even the emulator itself has not been updated.

- A [CSS rewrite](https://github.com/DamianS-eng/GBA-Emulator-Unblocked/tree/css-rewrite) is underway to improve navigation and readability.
- A [JS rewrite](https://github.com/DamianS-eng/GBA-Emulator-Unblocked/tree/js-rewrite) is underway to improve the flow of accessing the list of launchable titles from a database or reference file.
- A [fork to fetch](https://github.com/DamianS-eng/GBA-Emulator-Unblocked/tree/get-latest) the latest version of the emulator is also in the works.
